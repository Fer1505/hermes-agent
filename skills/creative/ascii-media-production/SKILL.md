# ASCII Media Production

Use this umbrella for ASCII output: static banners/text art, image-to-ASCII transforms, terminal-style illustrations, animated ASCII video, GIFs, and audio-reactive text visuals.

## Static ASCII art

Use for logos, banners, terminal splash screens, diagrams, and fun text transformations. Pick the rendering tool based on need: figlet/pyfiglet for text, cowsay/boxes for framed messages, image-to-ASCII scripts for raster sources.

## ASCII video and animation

Use for MP4/GIF/image-sequence output. Start with a creative concept, then choose input mode: video-to-ASCII, audio-reactive, generative, hybrid video+audio, timed lyrics/text, or narrated quote visuals. Treat typography, color palette, motion, and composition as the art direction, not afterthoughts.

## Production checklist

1. Define mood, visual story, palette, and output format.
2. Build one self-contained script or reproducible command chain.
3. Render a short proof or frame sample before long runs.
4. Verify output dimensions, duration, codec, and readability.
5. Keep any reusable shaders/effects in references or scripts.
